ASD 儿童康复陪伴机器人

三人执行计划网页版：时间分工、功能实现、器材采买、连线与应用功能设计。 产品定位为非医疗竞赛/毕业样机——辅助训练与客观记录，不诊断、不治愈、不做 ASD 分级。

UART↔雷达GPIO25/26R60A TX/RX交叉；5V TTL 需电平转换
USB3RDK Host有源 Hub→Gemini/麦/L610大电流勿硬扛板载口
AUDIORDK 3.5mm限幅→PAM8403→喇叭受控 5V 供电功放
  1. 电池 BMS → 12V→5V 稳压；RDK / Hub / L610 分支供电，大电流就近回流。
  2. 急停 NC 切断灯带与功放 5V；NO 接入 ESP32 GPIO4。
  3. ESP32：I²C（MPR121 + IMU）、WS2812 经 AHCT125、UART ↔ RDK。
  4. 相机、阵列麦经有源 USB3 Hub 接入 RDK。
  5. R60A UART；RDK 3.5mm → 限幅 → PAM8403 → 扬声器。
  6. 上电冒烟测试后烧录 firmware/esp32/asd_safety_island.ino。

禁止：舵机 / 云台；PCA9685 直接驱动 WS2812。

六、应用功能设计

安全优先级（不可被业务覆盖）

急停 > 倾倒/失联 > 持续高风险 > 人工暂停 > 安抚 > 训练 > 奖励

演示八场景（必达）

#场景
1靠近 → 低刺激唤醒短句
2入门级注视 / 触摸 / 问候训练
3非典型发音 → Top-K → 触摸二选一确认
4持续回避 → 降刺激
5哭声 / 高唤醒 → 安抚（不可自动强行恢复训练）
6长按暂停；急停 / 倾倒 → 静音熄灯
7断网本地落盘；联网 MQTT 幂等补发
8管理端会话与周趋势（非诊断报表）
允许：不适风险 0–4、客观行为统计、相对个人基线趋势。
禁止：医学诊断、治愈宣称、ASD 严重程度评分、默认上传原始音视频。
